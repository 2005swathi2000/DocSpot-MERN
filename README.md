# 🏥 DocSpot - Doctor Appointment Booking System

A full-stack healthcare appointment management platform developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js).

## 📌 Project Overview

DocSpot simplifies the process of booking doctor appointments and managing healthcare services through a modern web application.

The platform allows:

- Patients to book appointments online
- Doctors to manage appointments and schedules
- Admins to approve doctors and manage users

---

## 🚀 Features

- User Authentication & Authorization
- JWT-based Secure Login
- Patient Registration
- Doctor Application System
- Doctor Approval by Admin
- Appointment Booking
- Appointment Management
- Notification System
- User Profile Management
- Responsive UI Design
